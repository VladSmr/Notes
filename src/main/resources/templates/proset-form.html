Проставление оценок на IMDB

Оценки будут взяты из сохранённого дампа в указанной директории: самый свежий файл kp-ratings-{ID}-{метод}.csv ({ID} — ID профиля КП, {метод} — способ парсинга), а при его отсутствии — старый kp-ratings.csv. Кинопоиск не опрашивается. Уже обработанные фильмы (со статусом в дампе) будут пропущены.
Сейчас уже идёт процесс (?). Запуск нового процесса возможен только после его завершения.
Путь к папке, где лежит файл дампа kp-ratings-{ID}-{метод}.csv или kp-ratings.csv (результат этапа «Парсинг»; будет взят самый свежий по времени изменения). По умолчанию — рабочая папка приложения в вашем профиле (%USERPROFILE%\KP-IMDB-Importer). Можно указать свою.
