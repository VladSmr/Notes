Import ratings from KinoPoisk to IMDB

Found in your KP profile URL: https://www.kinopoisk.ru/user/USER_ID/
Directory where the kp-ratings.csv dump will be saved.
Browser needs KP login and also fills in missing original titles. API uses kinopoiskapiunofficial.tech and needs a token.
If the dump already exists in the log directory, data is read from it instead of calling KP/API — useful to re-run the IMDB part after errors.
Get it on kinopoiskapiunofficial.tech (Settings → API key).
