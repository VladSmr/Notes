Данные для импорта

Браузер (Selenium): парсинг всех оценок в Chrome. В браузере нужно будет войти в Кинопоиск. API (токен): быстрый парсинг через API — отдаёт все оценки. Браузер для парсинга не используется.
Находится в URL вашего профиля КП: https://www.kinopoisk.ru/user/USER_ID/
Получить можно на kinopoiskapiunofficial.tech (настройки → API-ключ).
Директория, куда будет сохранён дамп kp-ratings.csv.
Не указывайте корень диска (например C:\ или D:\) — Windows запрещает запись в корень системного диска. Укажите подпапку, например D:\notes\.
