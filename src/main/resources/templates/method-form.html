Данные для импорта

Браузер: парсинг всех оценок в Chrome. В браузере нужно будет войти в Кинопоиск. Kinopoisk API: быстрый парсинг через API — отдаёт почти все оценки. Браузер для парсинга не используется.
Находится в URL вашего профиля КП: https://www.kinopoisk.ru/user/USER_ID/
Получить можно на kinopoiskapiunofficial.tech (профиль → API-ключ). Регистрация бесплатная
Директория, куда будет сохранён дамп kp-ratings-{ID}-{метод}.csv ({ID} — ID профиля КП, {метод} — способ парсинга). По умолчанию — рабочая папка приложения в вашем профиле (%USERPROFILE%\KP-IMDB-Importer). Можно указать свою.
