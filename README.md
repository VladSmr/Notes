# KP → IMDB Rating Importer

Переносит оценки фильмов с **Кинопоиска** на **IMDB**.

## Как это работает

1. Парсятся все оценки пользователя с Кинопоиска (название, год, оценка, ссылка на фильм)
2. Сохраняется дамп всех оценок КП в `kp-ratings.txt`
3. Для каждого фильма выполняется поиск на IMDB
4. Если фильм уже оценён на IMDB с той же оценкой — пропуск (**пропущено**)
5. Если оценка отличается — пропуск с пометкой (**руками**)
6. Если фильм не нашёлся — запись в лог (**не найден**)
7. Если оценки нет — проставляется оценка с КП (**успешно**)

Между операциями пауза 3–5 секунд (имитация пользователя).

## Требования

- Java 21
- Chrome (для Selenium)
- chromedriver (скачать с https://googlechromelabs.github.io/chrome-for-testing/)

## Сборка и запуск

```bash
# Запуск приложения (тесты не выполняются)
./mvnw spring-boot:run

# Собрать jar с тестами
./mvnw package

# Собрать jar без тестов
./mvnw package -DskipTests

# Запустить только тесты
./mvnw test

# Только быстрые unit-тесты (без интеграционных)
./mvnw test -Dgroups=""
```

Приложение будет доступно по адресу `http://localhost:8080/notes/main`.

## Использование

1. Открыть `http://localhost:8080/notes/main`
2. Ввести **KinoPoisk User ID** (число из URL профиля: `kinopoisk.ru/user/ID/`)
3. Ввести **путь к директории для логов** (например `C:\logs\kp-imdb` или `./logs`)
4. Нажать "Next: Open IMDB Browser" — откроется Chrome
5. **Вручную** войти в аккаунт IMDB в открывшемся окне (если ещё не залогинены)
6. Нажать "Start Import" — импорт пойдёт автоматически
7. После завершения — страница со статистикой

## Файлы в директории логов

| Файл | Описание |
|------|----------|
| `imdb-import.log` | Подробный лог каждого фильма и итоговая статистика |
| `kp-ratings.csv` | Дамп всех оценок с КП перед началом импорта (title, year, rating, kp_url) |

### Формат лога (`imdb-import.log`)

Для каждого фильма записывается:
```
────────────────────────────────────────
Фильм 1/50
  Название: Начало (2010)
  Оценка КП: 8
  Ссылка КП: https://www.kinopoisk.ru/film/12345/
  IMDB: https://www.imdb.com/title/tt1375666/
  Оценка IMDB: 8
  Статус: успешно
```

### Статусы

| Статус | Описание |
|--------|----------|
| успешно | Оценка проставлена на IMDB |
| не найден | Фильм не найден на IMDB |
| пропущено (уже стоит оценка) | На IMDB уже стоит такая же оценка |
| руками (оценки отличаются) | На IMDB стоит другая оценка |
| ошибка | Произошла ошибка при обработке |
