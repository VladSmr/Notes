# KP → IMDB Rating Importer

Переносит оценки фильмов с **Кинопоиска** на **IMDB**.

## Как это работает

1. Оценки пользователя получаются одним из четырёх способов (выбор на странице приложения):

   | Способ | Ключ | Что делает | Для кого | Что нужно |
   |--------|------|------------|----------|-----------|
   | **Browser (Selenium)** | `selenium` | Полный парсинг всех оценок в открытом Chrome (залогиненная сессия), догружает оригинальные названия | Любое число оценок; медленнее остальных | ID пользователя КП, вход в КП в Chrome |
   | **API (token)** | `api` | Быстрый парсинг через kinopoiskapiunofficial.tech без браузера | До **~1500 последних оценок** (API столько и отдаёт, ранние теряются) | ID пользователя КП, API-токен |
   | **API + Browser (гибрид)** | `hybrid` | Первые ~1500 оценок (последние) через API, более старые добираются через Chrome (со страницы, следующей за покрытой API; дубликаты по kpId отбрасываются) | **Больше 1500 оценок** — быстро и без потерь | ID пользователя КП, API-токен, вход в КП в Chrome |
   | **Сохранённый дамп** | `saved` | КП не опрашивается: оценки читаются из `kp-ratings.csv` в директории логов | Повторный прогон после ошибок/остановки (уже обработанные фильмы пропускаются) | Только директория с дампом |

2. Дамп всех оценок сохраняется в `kp-ratings.csv` (перезаписывается после каждых 5 обработанных фильмов, чтобы статусы появлялись даже при остановке приложения).
3. В начале (страница «Prepare both sites») приложение через Selenium читает **реальное число оценок на КП** и показывает его на вебе; при способах с API рядом выводится, сколько записей вернул API, чтобы расхождение было видно сразу.
4. Для каждого фильма выполняется поиск на IMDB (по imdbId из дампа/API или по названию и году на странице поиска):
   - если оценка уже стоит та же — пропуск (**пропущено (уже стоит оценка)**);
   - если оценка отличается — пропуск (**руками (оценки отличаются)**);
   - если фильм не нашёлся — **не найден**;
   - иначе проставляется оценка с КП (**успешно**), после чего результат проверяется повторным чтением оценки.
5. Между фильмами пауза 1–2 секунды (имитация пользователя). Ход импорта виден на странице в реальном времени (SSE): прогресс-бар, кнопки **Pause / Continue / Stop**.

## Требования

- Java 21
- Chrome (для Selenium; chromedriver не нужен — Selenium Manager скачает сам)
- API-токен Кинопоиска с https://kinopoiskapiunofficial.tech — только для способа API

## Сборка и запуск

```bash
# Запуск приложения
mvnw spring-boot:run

# Собрать jar
mvnw package -DskipTests=false
```

> Внимание: в `pom.xml` по умолчанию `skipTests=true`, поэтому `mvn test` без аргументов **пропускает тесты**. Запускай так:

```bash
# Unit-тесты (36 шт.)
mvn test -DskipTests=false

# Включая интеграционные тесты (реальные сайты КП/IMDB, отмечены @Tag("integration"))
mvn test -DskipTests=false -Dgroups=integration
```

Приложение доступно по адресу `http://localhost:8080/notes/main`.

## Использование

1. Открыть `http://localhost:8080/notes/main`.
2. **Шаг 1 — выбор способа**: четыре карточки с описанием (Browser / API / API + Browser / Сохранённый дамп) и пояснением, для кого каждый подходит. Выбрать и нажать «Next».
3. **Шаг 2 — данные для способа**: форма показывает только нужные поля:
   - Browser — ID пользователя КП и директорию логов;
   - API и гибрид — дополнительно API-токен;
   - Сохранённый дамп — только директорию, где лежит `kp-ratings.csv`.
4. Нажать «Next: Open IMDB Browser» — откроется Chrome. На странице показывается число оценок на КП (и при API/гибриде — сколько вернул API).
5. **Вручную** войти в аккаунт IMDB в открывшемся окне (новая вкладка).
6. Нажать **Start Import** — импорт пойдёт в фоне, страница с прогрессом обновится автоматически.
7. Во время импорта доступны кнопки:
   - **Pause** — пауза после текущего фильма, **Continue** — продолжить;
   - **Stop** — полная остановка (после текущего фильма, дамп сохраняется);
   - если `kp-ratings.csv` открыт в Excel, импорт встаёт на паузу с подсказкой закрыть файл и нажать Continue.
8. После завершения — страница со статистикой и таблицей по каждому фильму.

## Файлы в директории логов

| Файл | Описание |
|------|----------|
| `kp-ratings.csv` | Дамп оценок КП со статусами импорта. UTF-8 с BOM, разделитель `;`, заголовок `title;original_title;english_title;year;rating;kp_id;imdb_id;status;error`. Запись атомарная (сначала `.tmp`, затем rename) — при сбое файл не усекается. |

Подробный лог хода импорта пишется в консоль приложения (SLF4J).

### Статусы (колонка `status` в CSV)

| Статус | Описание |
|--------|----------|
| успешно | Оценка проставлена на IMDB |
| не найден | Фильм не найден на IMDB |
| пропущено (уже стоит оценка) | На IMDB уже стоит такая же оценка |
| руками (оценки отличаются) | На IMDB стоит другая оценка |
| ошибка | Произошла ошибка при обработке |

Статусы записываются в дамп по ходу импорта — при повторном запуске из дампа уже обработанные фильмы пропускаются.

├── src/main/resources/templates/       # main, login-sites, importing, success, error
